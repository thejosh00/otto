Icon alone, cropped to the gate mark — this is what survives at 16–32px: terminal tab, favicon, tmux window title.

Why this mark

Gate + token. Two pillars and a crossbar read as a wicket gate; the amber circle sits mid-transit between them — one phase's output passing a checkpoint before the next begins. It's the same shape whether you're picturing a human gate or `otto state check-authorized`.

Monospace wordmark. Same face the binary prints in your terminal, so the logo doesn't look like a different product from the tool.

Blinking cursor, not a period. The block after otto blinks in the real file — an idle composer, the thing a session manager reads as safe to re-prompt.

Static crops above have hardcoded ink for comparison. assets/logo.svg is the one file that ships — it adapts on its own.
